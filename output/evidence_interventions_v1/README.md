# RA-CEDA v3.2 — Pilot-50 Evidence Interventions

Exploratory evidence-deletion and evidence-masking sensitivity experiment.

## Contents
- Original Qwen intervention generations and error history
- Exact paired prompt variants and intervention plans
- JSON recovery assessments and recovered answer candidates
- Paired answer-choice comparisons against control
- Matched real-versus-sham summaries
- Final JSON and Markdown pilot report
- SHA-256 backup manifest

## Interpretation
This is an exploratory pilot, not a confirmatory clinical evaluation.
The current workflow has no gold labels for these examples. Choice changes
measure answer sensitivity, not correctness or hallucination reduction.
Recovered-answer comparisons are subject to selection bias and small
matched samples. Verifier signals are not ground truth.

Original generations were not regenerated or edited during finalization.
No model weights or credentials are included.
