# CECS Pairwise Dependence Features

Exploratory pairwise evidence-dependence features for the RA-CEDA pilot.

- Claim rows: 106
- Candidate pairs: 4207
- Same-summary pairs: 2727
- Exact-text-match pairs: 0
- Pairs with token Jaccard overlap >= 0.8: 7

Same-summary provenance, exact text identity, and lexical overlap are distinct
signals. Lexical overlap does not establish semantic redundancy; distinct
summaries do not guarantee independence. No clinical support decisions or
confirmatory thresholds are applied in this stage.
